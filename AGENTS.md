# NovelForge AI Development Memory

This workspace is for NovelForge AI, a local-first AI writing workbench for long-form serialized novels.

Before starting any implementation phase, read these files:

1. `docs/project-memory.md`
2. `docs/product-memory-design.md`
3. `docs/development-log.md`

Primary source document:

- `/Users/shaola/Downloads/开发文档/长篇少说开发.md`

Current development rule:

- Build the local MVP first.
- Keep scope anchored to the active phase.
- Do not add SaaS, team collaboration, payment, mobile apps, cloud sync, or automatic WeChat publishing during MVP.
- Preserve author control: AI output may suggest changes, but formal settings, characters, world rules, timelines, and foreshadows must only change after user approval.
- Preserve long-form continuity: structured memory, chapter summaries, setting versions, character state, foreshadow tracking, and continuity reports are core value, not optional polish.

After completing any future development phase:

1. Update `docs/development-log.md`.
2. Update `docs/project-memory.md` if scope, architecture, commands, or product decisions changed.
3. Run the relevant checks for that phase.
4. Summarize what changed and what should be remembered next time.
